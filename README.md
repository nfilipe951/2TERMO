## Sobre o projeto

Este repositório reúne os **projetos, atividades e exercícios desenvolvidos durante o 2º Termo do curso de Desenvolvimento de Sistemas**.

O objetivo é registrar minha evolução durante a formação e colocar em prática os conhecimentos adquiridos em sala de aula.

---

## Conteúdos

Durante este termo, os projetos estão relacionados ao desenvolvimento de sistemas, programação, banco de dados e desenvolvimento web.

### Backend

Desenvolvimento da lógica e funcionamento interno das aplicações, trabalhando com processamento de informações e regras de negócio.

### BCD — Banco de Dados

Atividades relacionadas à criação, organização e manipulação de bancos de dados.

### LIMA — Linguagem de Marcação

Desenvolvimento e estruturação de páginas web utilizando linguagens de marcação.
